# UI Design Patterns Showcase

A collection of modern UI design pattern implementations showcasing different popular design styles. Each project is a fully functional portfolio website built with React and Vite, demonstrating a specific design aesthetic.

## ?? Design Styles

### 1. Neo-Brutalism
**Location:** `./neo-brutalism/`

Bold, unapologetic design with thick borders, vibrant colors, and strong shadows. Features sharp edges, high contrast, and a rebellious aesthetic inspired by brutalist architecture.

**Key Characteristics:**
- Thick black borders (3-4px)
- Bold, flat colors
- Heavy drop shadows
- Geometric shapes
- High contrast typography

---

### 2. Glassmorphism
**Location:** `./glassmorphism/`

Modern, elegant design with frosted glass effects, transparency, and subtle blurs. Creates a sense of depth with layered transparent elements.

**Key Characteristics:**
- Backdrop blur effects
- Semi-transparent backgrounds
- Subtle borders
- Soft shadows
- Light, airy feel

---

### 3. Minimalism
**Location:** `./minimalism/`

Clean, simple design focusing on essential elements only. Embraces whitespace, subtle typography, and restrained color palettes.

**Key Characteristics:**
- Abundant whitespace
- Limited color palette (2-3 colors)
- Clean typography
- Simple geometric shapes
- Focus on content

---

### 4. Skeuomorphism
**Location:** `./skeuomorphism/`

Realistic design mimicking real-world materials and textures. Features depth, shadows, and visual affordances that resemble physical objects.

**Key Characteristics:**
- Realistic textures and gradients
- Multi-layer shadows
- Embossed/debossed effects
- 3D-like appearances
- Material-inspired colors

---

### 5. Claymorphism
**Location:** `./claymorphism/`

Soft, inflated design with clay-like 3D elements. Combines the depth of skeuomorphism with modern flat aesthetics.

**Key Characteristics:**
- Soft, rounded shapes
- Inner and outer shadows
- Pastel color palettes
- Puffy, inflated appearance
- Smooth gradients

---

### 6. Liquid Glass
**Location:** `./liquid-glass/`

Fluid, organic design with glossy transparent surfaces. Features flowing shapes, gradient meshes, and dynamic glass-like effects.

**Key Characteristics:**
- Gradient mesh backgrounds
- Glossy reflections
- Fluid, organic shapes
- Colorful transparency
- Dynamic animations

---

## ?? Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd ui-design-patterns
```

2. Navigate to any design pattern folder:
```bash
cd neo-brutalism
# or
cd glassmorphism
# or any other pattern
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open your browser and visit:
```
http://localhost:5173
```

### Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist/` folder.

## ?? Customization

Each project is fully customizable:

1. **Colors:** Modify CSS variables in `src/index.css`
2. **Content:** Edit `src/App.jsx` to change text and structure
3. **Fonts:** Change font imports in `index.html`
4. **Assets:** Replace images in `src/assets/` and `public/`
